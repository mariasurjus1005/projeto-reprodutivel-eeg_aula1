# projeto-reprodutivel-eeg_aula1
##Análise Reprodutível de Sinais EEG — EEGMAT
###Sobre o projeto

Este repositório apresenta o desenvolvimento de uma análise reprodutível de sinais de eletroencefalografia (EEG), utilizando o dataset EEG During Mental Arithmetic Tasks (EEGMAT), disponibilizado pelo PhysioNet.

O conjunto de dados contém registros de EEG obtidos durante tarefas de aritmética mental, permitindo a investigação das características dos sinais cerebrais durante diferentes condições experimentais.

O projeto foi desenvolvido como parte das atividades relacionadas à reprodutibilidade científica, buscando garantir que as etapas de obtenção dos dados, processamento e análise possam ser reproduzidas por outros pesquisadores em um ambiente computacional independente.

###Objetivo

O objetivo deste projeto é realizar uma análise exploratória e processamento dos sinais EEG disponíveis no dataset EEGMAT no physionet, documentando todas as etapas computacionais necessárias para obtenção dos resultados.
